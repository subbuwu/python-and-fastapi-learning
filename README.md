# Python & FastAPI Learning

A collection of projects built while learning Python, FastAPI, and backend development.

## Projects

### 1. Task Tracker CLI

A simple command-line task manager built with Python that stores tasks locally in a JSON file.

**Project:** [roadmap.sh/task-tracker](https://roadmap.sh/projects/task-tracker)  
**Source Code:** [py/task-cli](https://github.com/subbuwu/python-and-fastapi-learning/tree/main/py-projects/task-cli)

### 2. GitHub Activity CLI

A Python command-line tool that fetches recent GitHub activity using the GitHub API and summarizes events such as pushes, stars, issues, and pull requests.

**Project:** [roadmap.sh/github-user-activity](https://roadmap.sh/projects/github-user-activity)  
**Source Code:** [github-events-api](https://github.com/subbuwu/python-and-fastapi-learning/tree/main/py-projects/github-events-api)

### 3. Markdown Note-taking API

A Python REST API built with FastAPI and SQLite to create, upload, and render Markdown notes, with grammar checking powered by LanguageTool.

**Project:** [roadmap.sh](https://roadmap.sh/projects/markdown-note-taking-app)  
**Source Code:** [md-notes-taking](https://github.com/subbuwu/python-and-fastapi-learning/tree/main/py-projects/md-notes-taking)
