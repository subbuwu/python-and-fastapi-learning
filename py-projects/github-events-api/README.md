# GitHub Activity CLI

A simple command-line tool built with Python that fetches and summarizes a GitHub user's recent activity using the GitHub API.

## Features

- Fetch recent GitHub events for any user
- Summarize pushes, stars, issues, and other activities
- Group events by repository and aggregate push commit counts
- Handle API errors and invalid usernames

## Usage

```bash
python main.py subbuwu
```
